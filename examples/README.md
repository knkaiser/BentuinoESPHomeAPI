# Entity examples

The 22 per-entity PlatformIO sample projects live under **[`firmware/examples/`](../firmware/examples/README.md)** (not at the repo root — they share the library at `firmware/lib/ESPHomeAPI`).

```bash
cd firmware/examples/sensor   # or light, switch, fan, …
pio run -e esp32dev -t upload
```

See [`firmware/examples/README.md`](../firmware/examples/README.md) for the full table and build instructions.
